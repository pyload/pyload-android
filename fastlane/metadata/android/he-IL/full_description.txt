התחברו למנהל ההורדות pyLoad ממכשיר Android. האפליקציה דורשת מופע pyLoad Core בגרסה 0.5.x הפועל במחשב, בשרת או במארח Docker.

התקינו את pyLoad מ-PyPI (https://github.com/pyload/pyload#quick-start), או השתמשו באימג' Docker של LinuxServer: https://docs.linuxserver.io/images/docker-pyload-ng.

תכונות:
- הגדרת מספר שרתי pyLoad ומעבר ביניהם
- סריקת קוד QR למילוי פרטי החיבור לשרת
- הצגת מצב ההורדה, ההתקדמות, המהירות ומצב השרת
- עיון בתור ובאוסף; מחיקה, העברה, הפעלה מחדש וביטול של הורדות
- הוספת קישורים, כולל דרך תפריט השיתוף של Android
- העלאת קובצי מכולה כגון DLC ו-CCF
- הזנת קאפצ'ות וניהול חשבונות
- הפעלה וכיבוי של הורדות ושל התחברות מחדש
- הצגה ועריכה של הגדרות השרת
- חיבור SSL עם אפשרות להגדיר אימות אישורים
- בחירה בערכת נושא בהירה, כהה או לפי הגדרות המערכת
- שימוש ב-Click'N'Load לשליחת קישורים או קובצי DLC לשרת מוגדר

כדי להתחבר, הוסיפו שרת והזינו את הכתובת ואת מפתח ה-API שלו. צרו מפתח API ב-pyLoad דרך הגדרות ← משתמשים ← פעולות ← ניהול מפתחות API ← יצירה. שמרו על המפתח; pyLoad מציג אותו רק בעת יצירתו.

סרקו קוד QR כדי למלא במהירות את פרטי תצורת השרת.

דווחו על בעיות באפליקציה בכתובת https://github.com/pyload/pyload-android/issues

זהו לקוח האנדרואיד הרשמי עבור מנהל ההורדות pyLoad. עליך להריץ את pyLoad על המחשב או השרת שלך.

תכונות:
- הוספת קישורים דרך אפשרות השיתוף (למשל Chrome/YouTube -> pyLoad)
- הוספת חבילות, או העלאת קבצי מכולה (DLC, CCF וכו')
- הצגת הורדות נוכחיות
- הצגת תור/אוסף
- מחיקה/העברה/הפעלה מחדש של חבילות
- ביטול הורדות
- הזנת קאפצ'ות להורדות
- החלפת הורדה/חיבור מחדש
- עריכת הגדרות צד שרת
- הצגת חשבונות
- חיבור SSL מאובטח לשרת

דרוש מפתח API כדי לחבר את האפליקציה למופע ה-pyLoad שלך. פתח את pyLoad בדפדפן ועבור אל:
הגדרות ← משתמשים ← ליד שם המשתמש שלך הקש על פעולות ← ניהול מפתחות API ← צור.

אנא דווח על כל בעיה בלקוח כאן: https://github.com/pyload/pyload-android/issues

Dies ist der offizielle Android-Client für den pyLoad Download Manager. Sie müssen pyLoad auf Ihrem PC oder Server ausgeführt haben.

Features:
- Links über die Share-Option hinzufügen (z. B. Chrome/YouTube -> pyLoad)
- Pakete hinzufügen oder Containerdateien hochladen (DLC, CCF etc.)
- Aktuelle Downloads anzeigen
- Warteschlange/Linksammler anzeigen
- Pakete löschen/verschieben/neu starten
- Downloads abbrechen
- Captchas für Downloads eingeben
- Download/Reconnect umschalten
- Serverseitige Einstellungen bearbeiten
- Konten anzeigen
- Sichere SSL-Verbindung zum Core

Sie benötigen einen API-Schlüssel, um die App mit Ihrer pyLoad-Instanz zu verbinden. Öffnen Sie pyLoad in Ihrem Browser und navigieren Sie zu:
Einstellungen → Benutzer → Tippen Sie neben Ihrem Benutzernamen auf Aktionen → API-Schlüssel verwalten → Generieren.

Bitte melden Sie alle Probleme mit dem Client hier: https://github.com/pyload/pyload-android/issues
